# CO1_AT1 — Design and Analysis of Algorithms

This folder contains the Question 1 Python implementations and report materials for CO1 AT1.

## Structure
- `Question_1/Source_Code/`: ten Python programs.
- `Question_1/Report/`: report and evidence screenshots.

## Programs
1. Factorial using a loop
2. Fibonacci series
3. Sum of natural numbers
4. Sum of squares
5. Sum of cubes
6. Natural-number series and sum
7. Square series and sum
8. Cube series and sum
9. Prime-number check
10. Prime numbers up to n

## Run a program
Use Python 3 from a terminal, for example:
```bash
python Question_1/Source_Code/01_factorial.py
```

The original archive containing the complete report PDF and screenshots is also retained at the repository root: [CO1_AT1.zip](../CO1_AT1.zip).
